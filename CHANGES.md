# Changes

This file tracks notable new functionality added to pdp11gui. See `CLAUDE.md` for the rule that keeps it up to date.

## 2026-07-24

- **"SimH direct" connection.** A new console connection type, selectable in the settings dialog as "SimH direct (pdp11gui launches SimH)". Instead of requiring the user to start `open-simh` by hand and configure its remote console, pdp11gui now launches the `pdp11` executable itself (found on `PATH`) using a generated copy of the chosen `.ini` file, and connects to it over two telnet links: one to SimH's "remote console" (the `sim>` command interface used for examine/deposit/run/reset) and one to the emulated PDP-11's own serial console. See `ConsolePDP11SimHU.pas` and `SerialIoHubU.Physical_InitForSimhProcess`.
- **CPU run-state tracking for the SimH console.** `ConsolePDP11SimHU.pas` now tracks whether the emulated CPU is actually running or halted (`TSimhCpuState`), derived only from confirmed events on the remote console (a `"Simulator Running..."` acknowledgment, an explicit halt message, or any `sim>` prompt reappearing) rather than assumed from whichever button was clicked. This fixed a cluster of related bugs: `Halt` no longer sends `^E` into an already-idle session (which SimH would silently ignore, leaving the displayed PC as `?`); a program that self-halts immediately after `Run` (eg. no code loaded, PC pointing at zeroed/HALT-opcode memory) is now detected and the UI updated automatically, without waiting for a `Halt` click that would otherwise send nothing. Detection is entirely event-driven with no timeout-based guessing - an earlier version of this fix that used a bounded wait after `Run` to decide "did it self-halt?" turned out to be a real hazard: guessing wrong on a genuinely-running program caused an unsolicited command to interrupt it, which SimH's remote console has no ordinary way to recover from (only `^E` resumes from that state, not a plain `RUN` retry).
- **"SimH Remote Console Log" window.** New optional MDI window (Connection menu) showing a live, timestamped transcript of every command sent to and phrase recognized from SimH's remote console - the protocol-level view used to diagnose the run-state issues above, kept as a permanent debugging aid instead of one-off log statements. See `FormSimhRemoteLogU.pas`.
